# 📱 React Native Axios CRUD Demo

Bu proje, React Native, Redux Toolkit ve Axios kullanılarak hazırlanmış basit bir CRUD uygulamasıdır. JSONPlaceholder API üzerinden kullanıcılar, gönderiler (posts), albümler (albums) ve yapılacaklar (todos) listelenir ve yönetilir.

## 🚀 Özellikler

Kullanıcıları listeleme ve detay sayfası

### Posts: listeleme, ekleme, silme, düzenleme

### Albums: listeleme

### Todos: kullanıcıya göre görevleri gösterme

### Axios ile GET / POST / PATCH / PUT / DELETE işlemleri

### Formik + Yup ile form yönetimi

### Redux Toolkit (createAsyncThunk) ile global state yönetimi

### React Navigation ile ekran geçişleri

## 🧰 Kullanılan Teknolojiler
